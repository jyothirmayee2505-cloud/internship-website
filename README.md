# Responsive Multi-Page Website

Built by Somula Jyothirmayee during the CODTECH IT Solutions web development internship (06 May – 06 June 2026).

## Features
- Home, About, Projects and Contact pages with consistent navigation
- Responsive layout (Flexbox, Grid, media queries), mobile-first
- Mobile menu toggle and live screen-width indicator (JavaScript)
- Contact form with client-side validation
- Accessible: skip link, visible focus, labelled fields, reduced-motion support

## Run locally
Open `index.html` in a browser, or run a local server:
```
python -m http.server 8000
```
then visit http://localhost:8000

## Structure
```
index.html  about.html  projects.html  contact.html
css/style.css   js/main.js   images/
```

## Tech
HTML5, CSS3, JavaScript (ES6), VS Code, Chrome DevTools, Git and GitHub.
